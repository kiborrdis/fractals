# Spline Graph Editor

Visual editor for B-spline animation curves. The spline curve is shown in yellow, with the control frame displayed in gray. Manipulate control points to shape the smooth curve that defines how a parameter animates over time.

## Toolbar

- **Preview (eye icon):** Toggle hover preview to see how values affect the fractal as you move the cursor.
- **Add point (scissors icon):** Click on the graph to add new control points to the spline.
- **Delete point (trash icon):** Click on existing control points to remove them.
- **Draw new (pen icon):** Enter draw mode to create an entirely new spline from scratch.
- **More menu:** Access "Edit fractal map" for visual parameter editing on the fractal.

Drag existing control points to reshape the curve. The B-spline interpolation ensures smooth, continuous transitions without sharp corners.
