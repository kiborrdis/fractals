# Recording Start Time

Specifies which moment in the animation timeline the recording should begin, in seconds.

Use this to skip ahead to a specific part of your animation rather than always starting from the beginning. The recording timeline highlights the window from start time through start time + duration, so you can visually confirm which portion of the animation will be captured.

## Range

0 to 3600 seconds (1 hour), with 0.1-second precision.

Adjustable in the recording settings panel. This setting is locked during an active recording.
