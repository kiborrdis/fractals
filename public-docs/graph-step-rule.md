# Step Rule Graph Editor

Visual editor for step-based animation rules where parameters move through discrete positions with configurable transitions between them.

Step points are displayed as vertices on the graph, color-coded by their transition type. Click on a step point to select it and edit its transition settings in the panel below.

## Toolbar

- **Help (? icon):** Show documentation for this feature.
- **Add step (scissors icon):** Click on the graph to add new step points.
- **Normalize (navigation icon):** Distribute step points evenly across the timeline.
- **More menu:** Access "Edit fractal map" for visual parameter editing.

## Editing Steps

Select a step point to configure its transition — choose from different easing functions (linear, sine, elastic, etc.) and adjust the duration. This gives precise control over how the parameter moves between each position.
