# Draw New Spline

Creates a new B-spline animation path by placing control points directly on the graph. Use this when you want to start fresh rather than modifying an existing spline.

## How to Use

1. Enter draw mode from the spline editor toolbar (pen icon).
2. Click on the graph to place control points — each click adds a new point.
3. The spline preview updates as you add points.
4. Use the scissors icon to toggle point adding on or off.
5. Use the trash icon to switch to delete mode and remove misplaced points.

## Finishing

- **Confirm (green checkmark):** Apply the new spline and return to the spline editor.
- **Cancel (red X):** Discard the new spline and return without changes.
