# Recording Timeline

A collapsible timeline panel below the fractal viewport in recording mode. Displays all animated parameters as line graphs with the recording window (start time to start time + duration) highlighted as a colored overlay.

## Features

- **Animation graph:** Shows all parameter values plotted over time, with the X-axis representing time and Y-axis representing normalized parameter values.
- **Recording window overlay:** A colored rectangle highlighting the portion of the timeline that will be captured in the recording.
- **Current time cursor:** A vertical line showing the current playback position.
- **Hover preview:** Move the cursor over the timeline to preview how the fractal looks at any point in time.
- **Collapsible:** Click the collapse button to minimize the timeline and free up viewport space.

Use this timeline to verify which animations will be captured before starting the recording. It mirrors the main timeline tool but is read-only, designed for reviewing and previewing rather than editing.
