# Trap Edit Mode

An interactive overlay on the fractal viewport that lets you visually create, position, and modify orbit trap shapes by dragging them directly on the fractal image.

## How to Use

1. Enable trap edit mode from the trap editor in the sidebar (click "Edit traps").
2. Trap shapes appear as white outlines on the viewport.
3. Drag trap handles to reposition or resize shapes.
4. Hover over a trap's badge in the floating panel to highlight it on the viewport (shown in yellow).

## Floating Panel

When trap edit mode is active, a panel appears on the viewport with:

- **Add buttons:** Create new trap shapes — line (−), circle (○), or segment (→).
- **Trap list:** Shows all current traps by type and index, with remove buttons (×) for each.
- **Exit:** Click "Exit edit mode" in the sidebar or toggle the edit button to leave.

Trap edit mode is only available when trap coloring is enabled.
