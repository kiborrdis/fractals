# Trap Distance Multiplier

Controls the intensity of trap coloring by scaling the distance values before they are mapped to the trap gradient. This multiplier is applied after taking the square root of the raw trap distance.

## Effect

- **Higher values:** More vivid, pronounced trap patterns with wider color bands.
- **Lower values:** Subtle, compressed trap effects concentrated near the trap shapes.
- **Default:** 25

## Range

0 to 1,000,000. Start with the default and adjust to taste — small changes can have a large visual impact depending on your trap shapes and gradient.
