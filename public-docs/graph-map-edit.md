# Fractal Map Editor

A specialized editing mode that renders the fractal in the graph background, letting you pick the complex constant C value by clicking directly on the fractal image.

A white line is drawn from the origin (0, 0) to the current C value, helping you track the parameter position. Hover over the fractal to preview how different C values change the output in real time.

## How to Use

1. Open from the "More" menu in any 2D parameter graph editor.
2. Hover over the fractal to preview different C values.
3. Click to set the value.
4. Use pan controls to explore different regions of the fractal.

## Finishing

- **Confirm (green checkmark):** Apply the selected value.
- **Cancel (gray X):** Discard changes and return to the previous editor.
