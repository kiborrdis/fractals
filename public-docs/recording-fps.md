# Recording FPS

Sets the frame rate (frames per second) for the exported video.

## Available Options

- **24 fps:** Cinematic feel, smaller file size.
- **30 fps:** Standard video, good balance of smoothness and size.
- **60 fps:** Smooth motion, best for fast animations, larger file.

Higher frame rates produce smoother playback but increase rendering time and file size proportionally. This setting is locked during an active recording.
