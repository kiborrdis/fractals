# Recording Resolution

Sets the pixel dimensions of the exported video.

## Presets

| Preset | Resolution |
|--------|-----------|
| 1080p | 1920 × 1080 |
| 720p | 1280 × 720 |
| 480p | 854 × 480 |
| 360p | 640 × 360 |
| 180p | 320 × 180 |

## Custom Resolution

Select "Custom" to enter any width (100–7680) and height (100–4320) in pixels.

When changing resolution, the viewport offset scales proportionally to maintain your current composition. This setting is locked during an active recording.
