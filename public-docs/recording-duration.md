# Recording Duration

Sets how long the exported video will be, in seconds.

## Range

1 to 300 seconds (5 minutes).

The total number of frames rendered is calculated as FPS × duration. For example, 60 fps × 10 seconds = 600 frames.

The recording timeline shows the duration window as a highlighted overlay so you can see exactly which portion of the animation will be captured. Adjust together with start time to select the desired animation segment. This setting is locked during an active recording.
