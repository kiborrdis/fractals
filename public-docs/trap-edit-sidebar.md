# Trap Editor (Sidebar)

The sidebar panel for managing orbit trap shapes used in trap coloring. Shows the current list of traps and provides controls for entering the visual editing mode.

## Controls

- **Edit traps button:** Toggles the visual trap editing mode on the fractal viewport, where you can drag and modify trap shapes directly. The button turns red when edit mode is active.
- **Trap count:** Displays the number of currently defined trap shapes.

## Available Trap Types

- **Point:** A single point trap — orbit distance is measured from this point.
- **Line:** An infinite line trap.
- **Circle:** A circular trap with configurable radius.
- **Segment:** A line segment between two points.

Traps are defined in the trap coloring section and only affect the fractal when trap coloring is enabled.
