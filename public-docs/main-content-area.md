# Main Content Area

The central viewport displaying the live fractal render. This is where you see the result of all your parameter and coloring changes in real time.

## Viewport Controls

A floating toolbar provides navigation controls:

- **Zoom display:** Shows the current zoom level.
- **Pan toggle:** Enable or disable panning with mouse drag.
- **Select area:** Draw a rectangle to zoom into a specific region.
- **Reset viewport:** Restore the default zoom and pan position.
- **Zoom in/out:** Manual zoom buttons.

## Interaction

- **Drag** to pan the viewport (when pan is enabled).
- **Scroll** to zoom in and out.
- **Click** with the area selection tool to zoom into a drawn rectangle.

In recording mode, the viewport shows a recording frame overlay with draggable edges for adjusting the captured area and composition.
