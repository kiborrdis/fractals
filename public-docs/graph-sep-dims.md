# Separate Dimensions Graph

Visual graph editor for 2D vector parameters (like the complex constant C) where X and Y components are edited independently using separate rules.

Click anywhere on the graph to set a static value. Hover over the graph with preview mode enabled (eye icon) to temporarily see how different values affect the fractal.

## Toolbar

- **Preview (eye icon):** Toggle hover preview — move the cursor over the graph to see the fractal update in real time.
- **Help (? icon):** Show documentation for this feature.
- **More menu:** Access additional options like "Edit fractal map" for visual C parameter editing.
