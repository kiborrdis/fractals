# Recording Mode

Activates the video recording interface, replacing the normal editor with specialized controls for composing and exporting fractal animations as video files.

## How to Enter

Click the video camera icon in the sidebar header to toggle recording mode on or off.

## Recording Interface

When active, the editor switches to a recording-specific layout:

- **Preview viewport:** Shows the fractal with a recording frame overlay indicating the exact area that will be captured.
- **Recording sidebar:** Contains resolution, FPS, duration, and start time settings, along with recording controls.
- **Recording timeline:** A read-only timeline showing all parameter animations with the recording window highlighted.

## Workflow

1. Enter recording mode from the edit view.
2. Configure resolution, FPS, duration, and start time.
3. Adjust the recording frame position on the viewport if needed.
4. Preview the animation using the timeline.
5. Start recording — frames are rendered and encoded to video.
6. Download the finished video when complete.
